# LinguagemVBA

### Repositório dedicado a arquivos _.bas_, com múltiplas, funções para consultas

## Como usar:

- 1º Salvar o arquivo com extensão que rode os scripts **VBA**: .xlsm, .xlsb

- 2º Vá em: Arquivo>Opções>Personalisar Faixa de Opções>Guias Principais: ative a guia **Desenvolverdor**
  
- 3º Após baixar em sua máquina, importe o arquivo para a sua pasta de trabalho.
